# Norland Kenya Website

Static HTML/CSS/JavaScript website for norlandkenya.com.

## Included
- Home, Products, Opportunity, Events, About, Contact
- Seven campaign landing pages
- Privacy, Disclaimer and Terms pages
- Official Norland logo supplied by the client
- Three supplied promotional videos, compressed for web/mobile playback
- Products page populated from the Kenya wholesale/retail price list supplied on 2 October 2026
- 38 retail catalogue entries with KSh prices and WhatsApp order buttons
- Searchable product catalogue

## Important
The product list is based on the supplied price list. The list does not confirm stock availability. Product descriptions and health/product claims should be added only after the approved claims sheet is supplied.

## Deployment
Upload the contents of this folder to the domain's `public_html` directory on Hostinger or another static web host. Keep the folder structure intact.
